Mise en route

Étapes d'installation

Suivez chaque étape dans l'ordre avant de lancer le bot.

01

Installer Firefox Browser

Téléchargez et installez Mozilla Firefox depuis le site officiel pour assurer la compatibilité du navigateur.

Installer Firefox
02

Installer Python 3

Installez Python 3 sur votre PC et cochez bien Add Python to PATH lors de l'installation.

Télécharger Python
03

Télécharger et extraire le pack ZIP

Téléchargez VINCI BOT ALTISSIA By KHALID.zip avec votre code d'accès, puis faites Extraire tout dans un dossier.

04

Installer les dépendances et lancer le script

Ouvrez le terminal dans le dossier du bot, installez les packages requis puis exécutez python fr.py ou python en.py.

Exécution

Commandes rapides

fr.py — Français Module FR 
pip install -r requirements.txt
python fr.py
en.py — Anglais Module EN 
pip install -r requirements.txt
python en.py
