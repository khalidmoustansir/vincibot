Guide Pas-à-Pas

Installation & Lancement

Suivez ces 5 étapes simples pour installer et exécuter VINCI BOT ALTISSIA By KHALID.

01

Installer Firefox Browser

Téléchargez et installez Mozilla Firefox depuis le site officiel pour utiliser Altissia avec le navigateur recommandé :

https://www.mozilla.org/firefox/new/ Installer
02

Installer Python 3 (avec Add Python to PATH)

Téléchargez et installez Python 3 depuis le site officiel python.org en cochant impérativement la case "Add Python to PATH" lors de l'installation.

https://www.python.org/downloads/ Installer
03

Extraire VINCI BOT ALTISSIA By KHALID.zip & ouvrir CMD

Extrayez l'archive VINCI BOT ALTISSIA By KHALID.zip, ouvrez l'invite de commandes (CMD) et entrez dans le dossier du bot :

cd "VINCI BOT ALTISSIA By KHALID"
04

Installer les dépendances via requirements.txt

Installez automatiquement toutes les bibliothèques nécessaires (pyautogui, pycaw, comtypes) en une seule commande :

pip install -r requirements.txt
05

Passer en QWERTY, se connecter à Altissia & lancer le bot

Connectez-vous à votre compte Altissia sur Firefox, basculez votre clavier en QWERTY (Alt + Shift), puis lancez la langue souhaitée (Ctrl + C dans CMD pour arrêter) :

Parcours Français : py fr.py
Parcours Anglais : py en.py
